
Milestone 1: Security Data Aggregation & Threat Intelligence Layer :-


Objective of Milestone 1 :-
Our goal in Milestone 1 is NOT to detect attacks yet. We first need to collect security data, clean it, standardize it, enrich it, and prepare it for machine learning in Milestone 


Real World Example

Suppose an organization receives:

Firewall Logs
Login Logs
IDS Alerts
Vulnerability Reports
Threat Intelligence Feeds
Previous Incident Recrods

Firewall Logs :
| Timestamp | Source IP   | Destination IP | Action  |

| 10:00     | 192.168.1.5 | 8.8.8.8        | Allowed |



Login Log :

| Timestamp | Username | Failed Attempts |
| --------- | -------- | --------------- |
| 10:00     | admin    | 12              |

Vulnerability Feed :-

| CVE          | Severity |
| ------------ | -------- |
| CVE-2024-001 | Critical |
